# Мобильная презентация сметы

[Открыть смету](https://nikolaycergeevich.github.io/smeta-perevozki-mobile/)

Десять вертикальных слайдов 9:16 для владельца перевозок. Сайт объясняется через магазин: адрес, помещение, ремонт и администратор. Слайды листаются свайпом, кнопками «Назад» / «Далее» или клавиатурой. В финале — итог с позициями и получателями платежей.

Версия 1.1 от 17.10.2026. `dist/index.html` — самостоятельный файл: стили, сценарий и SVG-иллюстрации встроены внутрь. Его можно отправить отдельно и открыть без подключения к интернету. Шрифты системные; внешних изображений, аналитики и запросов к API нет.

## Условия клиентской версии

- Первый год: 45 199 ₽ при бюджете хостинга 10 000 ₽. Из них 35 000 ₽ исполнителю, 10 199 ₽ сторонним компаниям.
- Со второго года: около 10 420 ₽ без поддержки или около 20 420 ₽ с поддержкой.
- Цены хостинга и итогов описаны как «около»: подтверждённого верхнего предела тарифа нет.
- 35 000 ₽ — единый пакет создания сайта и первого года поддержки. Доработки после запуска оплачиваются отдельно.
- 100% предоплата — условие работы исполнителя.
- Словарик находится перед первым экраном оплаты. Ежегодные расходы показаны обычными строками сравнения.
- Кнопка вопроса и форма подготовки сообщения удалены по просьбе автора.
- Служебных пометок в клиентской презентации нет.

При нехватке высоты доступна вертикальная прокрутка внутри слайда. Размер текста не уменьшается ниже 16 px. Дополнительные услуги раскрываются на отдельном слайде; вложенных раскрытий нет.

## Исходники и сборка

- `src/index.html` — структура и тексты десяти слайдов.
- `src/illustrations.svg` — встроенные иллюстрации магазина и аналогий.
- `dist/style.css`, `dist/app.js` — оформление и навигация.
- `estimate-content.json` — существующие цены и условия сметы.
- `scripts/build_site.mjs` — проверка арифметики и сборка самостоятельного HTML.
- `dist/index.html` — готовая презентация, публикуемая GitHub Pages.

Старый PDF (`dist/smeta.pdf`) и его генератор сохранены как предыдущая версия. Новая презентация на него не ссылается; он не соответствует её оформлению.

```sh
node scripts/build_site.mjs
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Для сборки нужен Node.js без дополнительных пакетов. Для просмотра достаточно открыть `dist/index.html` или http://127.0.0.1:4173/.

## Обновление и публикация

После изменения исходников выполнить `node scripts/build_site.mjs` и проверить готовый HTML на телефоне. Сборка сверяет итоговые суммы и строки оплаты. Публикация папки `dist` запускается автоматически после push в `main` через GitHub Actions.

Старые ссылки `#price`, `#result`, `#start`, `#later` сохранены. Псевдонимы `#site`, `#payment`, `#ads` и `#services` ведут на соответствующие слайды. Без JavaScript все слайды доступны одной страницей.
