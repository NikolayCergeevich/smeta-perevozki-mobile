# Интерактивная смета сайта перевозок

[Открыть смету](https://nikolaycergeevich.github.io/smeta-perevozki-mobile/) · [Скачать PDF](https://nikolaycergeevich.github.io/smeta-perevozki-mobile/smeta.pdf)

Предложение по разработке сайта для человека без технической подготовки. Четыре коротких экрана: общая цена, результат, порядок работы и расходы после запуска. Кнопки «Далее» и «Назад» ведут по смете, верхнее меню позволяет открыть любой шаг.

Финансовые условия исходной версии 0.2 от 17.10.2026 и исходный PDF сохранены. Статус документа — «Черновик для обсуждения». Полные условия доступны в окнах подробностей; основной экран показывает главное простыми словами.

## Что изменилось для клиента

- Общая цена первого года показана сразу, рядом — когда и кому платить каждую сумму.
- Адрес и размещение объясняются без необходимости знать слова «домен» и «хостинг».
- Пакет разработки остаётся единой услугой за 35 000 ₽.
- Видно, какие материалы нужны от заказчика и что означает полная предоплата.
- Со второго года показаны два итога: 5 460 ₽ без поддержки и 15 460 ₽ с ней.
- Реклама и дополнительные задачи явно отделены как необязательные.
- Полные условия и PDF доступны без прохождения всех шагов. Старые ссылки на разделы продолжают работать.

Это оценка интерфейса и техническая проверка, а не результат исследования на реальных клиентах. Основной текст сохраняет читаемый размер; на маленьком экране или при увеличении текста допустима прокрутка вместо обрезания содержимого.

## Файлы

- `src/index.html` — шаблон четырёх экранов и подробных условий.
- `scripts/build_site.mjs` — сборка HTML из шаблона и существующих данных, проверка итоговых сумм.
- `dist/index.html` — готовый HTML, создаётся сборкой.
- `dist/style.css`, `dist/app.js` — оформление и навигация без сторонних зависимостей.
- `dist/smeta.pdf` — исходная смета на шести страницах.
- `estimate-content.json` — структурированное содержимое исходной сметы.
- `scripts/build_pdf.py` — исходный генератор PDF для Python с ReportLab и шрифтами DejaVu Sans по Linux-путям.
- `.github/workflows/pages.yml` — автоматическая публикация папки `dist` при push в `main`.

Для сборки нужен только Node.js, без npm-пакетов. Для просмотра не нужны сервер приложений или внешние API: GitHub Pages раздаёт готовые файлы. Внешние ссылки на тарифы Beget открываются только по нажатию.

## Локальный просмотр

Из корня репозитория:

```sh
node scripts/build_site.mjs
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/ в браузере.

## Обновление

Оформление и навигация редактируются в `dist/style.css` и `dist/app.js`, структура и краткие пояснения — в `src/index.html`, цены и полные условия — в `estimate-content.json`. После правок выполнить `node scripts/build_site.mjs` и включить созданный `dist/index.html` в коммит. GitHub Actions также запускает сборку перед публикацией.

При изменении финансовых условий нужно отдельно обновить PDF: он не пересобирается во время публикации. Сборка проверяет арифметику итогов; ручное изменение только готового HTML будет перезаписано.

После коммита и push в `main` дождаться успешного выполнения **Publish estimate to GitHub Pages** во вкладке Actions. В настройках Pages источником публикации выбран **GitHub Actions**.
