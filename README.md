# Интерактивная смета сайта перевозок

[Открыть смету](https://nikolaycergeevich.github.io/smeta-perevozki-mobile/) · [Скачать PDF](https://nikolaycergeevich.github.io/smeta-perevozki-mobile/smeta.pdf)

Предложение по разработке сайта: состав пакета, оплата, поддержка, реклама и дополнительные услуги. На телефоне разделы переключаются нижними вкладками, на компьютере — боковым меню.

Перенесена исходная версия 0.2 от 17.10.2026. Оформление, текст, цены и PDF сохранены без изменений. Статус документа — «Черновик для обсуждения».

## Файлы

- `dist/index.html` — готовый сайт со встроенными стилями, иконками и JavaScript.
- `dist/smeta.pdf` — исходная смета на шести страницах.
- `estimate-content.json` — структурированное содержимое исходной сметы.
- `scripts/build_pdf.py` — исходный генератор PDF для Python с ReportLab и шрифтами DejaVu Sans по Linux-путям.
- `.github/workflows/pages.yml` — автоматическая публикация папки `dist` при push в `main`.

Для просмотра и публикации не нужны сборка, npm, сервер приложений или внешние API. GitHub Pages раздаёт готовые файлы. Внешние ссылки на тарифы Beget открываются только по нажатию.

## Локальный просмотр

Из корня репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/ в браузере.

## Обновление

Изменения HTML выполняются в `dist/index.html`. При изменении цен или условий необходимо также обновить `estimate-content.json` и PDF: HTML не генерируется автоматически из JSON, а PDF не пересобирается во время публикации.

После коммита и push в `main` дождаться успешного выполнения **Publish estimate to GitHub Pages** во вкладке Actions. В настройках Pages источником публикации выбран **GitHub Actions**.
